## Implementation limits

- This catalogue stores rule descriptions for reference. It does not implement every once-per-turn limit, trigger, modifier, unit restriction, or automatic combat interaction.
- The transcript does not contain enough information to implement the full army composition and regiment structure. The system uses an unrestricted selection force rather than fabricated tournament restrictions.
- Battle formations, heroic traits, artefacts, spell lore and prayer lore are present in the faction reference entry as readable rules; enhancement eligibility and once-per-battle selection limits are not automated.
- This repository has been XML-parsed locally, but has not been loaded into a live New Recruit Builder session. Please test the import before relying on it.
